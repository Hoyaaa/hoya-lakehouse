## Who Am I

> _"데이터 흐름을 이해하고, 그 위에서 인사이트와 의사결정을 설계하는 데이터 분석가"_ 가 되고 싶습니다.

서비스의 **데이터 흐름 전체를 이해**하고, 숫자와 로그를 해석해 인사이트를 뽑아내는 일을 좋아합니다.  
필요하면 분석에 필요한 데이터를 모으거나 검증하기 위해 **간단한 앱/웹/스크립트를 직접 만들어 보는 편**입니다.

특히 관심 있는 도메인:
- 학식/캠퍼스처럼 **사람들이 매일 사용하는 공간**
- **금융/거래 데이터**처럼 숫자와 패턴이 중요한 영역

## Projects

### HacBokGS – 캠퍼스 통합 서비스 & 관리자 웹
`Android(Java/Kotlin)` `Firebase` `Vanilla JS` `Python/Selenium`

[👉 HacBokGS_package](https://github.com/Hoyaaa/hoya-lakehouse/tree/main/HacBokGS_package)

남서울대학교 학식·매점을 위한 **모바일 앱 + 관리자 웹 + 데이터 자동화 파이프라인** 통합 플랫폼. (4인 팀, 팀장)

- Firebase(Firestore·Auth·Storage) 기반 Serverless 아키텍처 설계
- Firestore Batch/Transaction으로 다중 상점 주문의 원자적 처리 및 동시성 제어 구현
- 실시간 조리 상태 감지 + Activity 생명주기를 고려한 Queue 기반 팝업 시스템 구현
- 시간 가중치 기반 혼잡도 추론 알고리즘 설계
- Canvas + PathMeasure 기반 커스텀 경로 애니메이션 구현
- Python(Flask + Selenium) 크롤링 서버와 관리자 웹 연동 → 식단 데이터 자동 수집·갱신
- 관리자 웹(주문·광고·게시판·혼잡도 관리) Vanilla JS로 단독 설계 및 구현

### G2B 입찰공고 자동 수집 & 필터링
`Python` `Selenium` `pandas` `openpyxl`

[👉 Webdata_Crawler_package](https://github.com/Hoyaaa/hoya-lakehouse/tree/main/Webdata_Crawler_package)

나라장터(G2B) 입찰공고를 자동 크롤링하고 엑셀 기반으로 정제하는 **데이터 자동화 파이프라인**.

- Selenium으로 공고 상세 페이지 자동 접근 및 핵심 필드 추출 (공고번호·기관·금액·기간)
- 10건 단위 체크포인트 저장으로 대량 처리 중 데이터 유실 방지
- 구조가 불규칙한 엑셀 파일에서 헤더를 동적 탐지하는 파싱 로직 구현
- 수십 개 제외 키워드를 단일 정규표현식으로 결합한 고속 필터링 처리
- 수작업 전 과정(공고 검색 → 데이터 복사 → 엑셀 정리)을 스크립트 하나로 자동화

### 영수증 OCR 자동 인식 & 클라우드 가계부
`Android(Kotlin)` `Firebase` `Google ML Kit` `Naver OCR API` `Google Sheets API`

[👉 imagehouseholdbook](https://github.com/Hoyaaa/hoya-lakehouse/tree/main/imagehouseholdbook)

영수증 이미지를 촬영하면 상품명·가격·수량을 자동 추출해 **Firebase와 Google Sheets에 동시 저장**하는 가계부 앱.

- ML Kit Document Scanner로 영수증 영역 자동 인식 및 보정
- Firestore `receiptJobs` 컬렉션 + SnapshotListener 기반 실시간 OCR 작업 상태 추적 (업로드 중 → 분석 중 → 완료)
- Naver OCR API + Retrofit2로 텍스트 추출 및 DTO 구조화
- Google Sheets API v4 + OAuth2 인증으로 외부 데이터 이중 저장 파이프라인 구성
- 구매 날짜·가맹점 기준 데이터 그룹화 및 "상품A 외 N건" 요약 UI 구현
