# 프로젝트명: 공공 입찰 데이터 수집 및 전처리 자동화 시스템

## 1. 개요 (Overview)

본 프로젝트는 나라장터(G2B)의 입찰공고 데이터를 자동으로 수집하고, 불필요한 데이터를 필터링하여 실무에 활용 가능한 형태로 정제하는 **데이터 자동화 파이프라인**입니다.

Selenium 기반의 웹 크롤링을 통해 공고 상세 정보를 자동 추출하고, Pandas 기반의 데이터 전처리를 통해 업무와 무관한 공고를 제거함으로써 기존의 반복적인 수작업을 완전히 자동화했습니다.

이를 통해 공고 검색, 데이터 수집, 엑셀 필터링까지 이어지는 전 과정을 하나의 스크립트 흐름으로 통합하여 **업무 효율성과 데이터 정확성을 동시에 확보**했습니다.

---

## 2. 기술 스택 (Tech Stack)

* **Language**: Python 3.x
* **Data Processing**: Pandas, Openpyxl
* **Web Automation**: Selenium WebDriver, Webdriver-manager
* **Text Processing**: Regular Expression (re), Glob
* **File Handling**: CSV, Excel (xlsx, xls)

---

## 3. 핵심 기능 (Key Features)

### 3.1. 입찰공고 상세 데이터 자동 수집

* Selenium을 활용하여 G2B 사이트의 검색 및 상세 페이지 접근을 자동화

* 엑셀에 정의된 공고번호 리스트를 기반으로 반복 처리

* 다음 핵심 필드 자동 추출

  * 입찰공고번호
  * 공고기관
  * 공고명
  * 사업금액 (우선순위 기반 필드 탐색)
  * 시작일시 / 종료일시

* 10건 단위 체크포인트 저장(CSV append)

  * 크롤링 중단 시에도 데이터 유실 최소화

---

### 3.2. 비정형 엑셀 구조 대응 데이터 로딩

* 엑셀 파일의 구조가 고정되어 있지 않은 상황을 고려하여

  * ‘공고명’ 또는 ‘제목’ 키워드를 기준으로 헤더 자동 탐지
* 모든 시트를 순회하여 실제 데이터 시작 지점을 동적으로 판단
* 컬럼명 정규화 및 중복 컬럼 처리 로직 적용

---

### 3.3. 키워드 기반 데이터 필터링 자동화

* 수십 개의 제외 키워드를 하나의 정규표현식으로 결합하여 고속 필터링 수행

* 공고명 기준으로:

  * 유지 대상 데이터
  * 제외 대상 데이터
  * 전체 원본 데이터
    를 각각 분리하여 저장

* 주요 제외 키워드 예시

  * 공사, 납품, 철거, 임대, 폐기물, 물류, 건설, 운송 등

---

### 3.4. 최신 데이터 자동 탐색 및 처리

* 지정 폴더 내 `입찰공고목록*.xls*` 파일 자동 탐색
* 수정시간 기준으로 가장 최신 파일 선택
* 수동 파일 선택 과정 제거 → 완전 자동화

---

### 3.5. 예외 처리 및 안정성 강화

* 웹 크롤링 중 발생하는 팝업 자동 처리
* 페이지 이동 상태 유지 로직

  * 상세 → 목록 복귀 보장
* 컬럼 탐색 실패 시 예외 발생 처리
* 크롤링 중단 상황 대비 중간 저장 구조

---

## 4. 시스템 흐름 (Flow)

```
[입력 데이터]
엑셀 공고번호 목록 -> 공고번호 리스트 생성

-> Selenium 크롤링 실행
-> G2B 접속 및 검색 자동화
-> 공고 상세 정보 추출
-> CSV 중간 저장 (10건 단위)

-> 최신 입찰공고목록 엑셀 탐색
-> 헤더 자동 탐지 및 DataFrame 생성
-> 키워드 기반 필터링 수행

-> 결과 저장
   - 전체 데이터
   - 필터링 데이터
   - 제외 데이터
```

## 5. 컴포넌트 구성 (Component Breakdown)

  * CSV 누적 저장

* 주요 기능

  * 최신 파일 자동 탐색
  * 헤더 자동 인식
  * 공고명 컬럼 탐지
  * 정규식 기반 데이터 분리
  * 다중 결과 파일 생성

## 6. 기술적 성과 및 문제 해결 (Highlight for Resume)

* **반복 업무 자동화**

  * 공고 검색 → 데이터 복사 → 엑셀 정리까지의 전 과정을 자동화하여
  * 기존 수작업 대비 처리 시간을 대폭 단축

* **비정형 데이터 처리 능력**

  * 구조가 일정하지 않은 엑셀 파일에서 헤더를 동적으로 탐지하는 로직 구현

* **정규표현식 기반 고성능 필터링**

  * 수십 개 키워드를 단일 패턴으로 결합하여 빠른 데이터 분류 처리

* **동적 웹 크롤링 안정성 확보**

  * 팝업 처리, 탭 전환, 페이지 복귀 로직을 통해 크롤링 실패율 최소화

* **데이터 유실 방지 설계**

  * 체크포인트 저장(Partial Save) 구조를 통해 대량 처리 환경에서 안정성 확보

* **확장 가능한 구조 설계**

  * 경로, 키워드, 컬럼 구조를 변수화하여 유지보수 및 확장 용이성 확보
